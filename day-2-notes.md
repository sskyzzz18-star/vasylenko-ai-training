# Day 2 — Git & GitHub
## 1. What is Git?
-Git is a tool for tracking changes in files and code.
## 2. What is the difference between Git and GitHub?
-Git is a tool on your computer. GitHub is a website for storing and sharing Git repositories online.
## 3. What is a repository?
-A repository is a project folder where Git tracks files and their changes.
## 4. What is a commit?
-A commit is a saved version of changes in a repository.
## 5. What does push do?
-Push sends your local commits to a remote repository, such as GitHub.
## 6. Why do we need git status?
-git status shows which files have changed and what Git is tracking.
## 7. Why shouldn't we store API keys and passwords in a public repository?
-Because anyone can see them and use them to access your accounts or services.
